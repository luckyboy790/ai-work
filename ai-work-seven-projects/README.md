- [末日战役](https://threebody.aihome.cyou/doomsday/)：`doomsday/`

- [太平洋一号·永夜浮城](https://threebody.aihome.cyou/pacific/)：`pacific/`
- [三体·无声证词](https://threebody.aihome.cyou/silent-testimony/)：`silent-testimony/`

- [三体·文明回声](https://threebody.aihome.cyou/echo/)：`echo/`

## 本地预览

运行 `python -m http.server 8000`，访问 `http://localhost:8000/作品文件夹/`。文明回声需要 WebGL 2；Three.js 依赖已包含。
